\chapter{论文终稿检查表}
\begin{enumerate}
  \item 页数是否为95至105页，且没有重复内容、无意义大图或空白凑页。
  \item 标题、正文、一至四级标题、数字英文、行距、页边距和段首缩进是否符合要求。
  \item 方正小标宋简体和仿宋GB2312是否来自合法授权文件并嵌入PDF。
  \item 单页页码是否居右空一字、双页页码是否居左空一字。
  \item 目录、书签、图表编号、交叉引用和GB/T 7714-2015参考文献是否正确。
  \item 三端截图是否来自实际应用并隐藏账号、令牌、密钥与个人材料。
  \item 所有调研数字能否回到匿名原始记录，所有性能数字能否回到日志。
  \item HarmonyOS 6创新表述是否聚焦原生适配、端云协同和国产生态，不作产权误述。
  \item 全部页面渲染为PNG后是否无重叠、缺字、裁切、黑块和模糊图片。
\end{enumerate}
